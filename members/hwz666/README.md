## 我的操作步骤（组员流程）
1. `git clone` 克隆组长仓库
2. `git checkout develop` + `git pull` 切到 develop 并拉取最新代码
3. `git checkout -b hwz666` 创建个人分支
4. 编写代码 → `git add` → `git commit` → `git push`
5. 在网页创建 Pull Request，等待组长审核合并
