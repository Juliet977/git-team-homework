## 我的操作步骤（组员流程）
1. `git clone` 克隆组长仓库
2. `git checkout develop` + `git pull` 切到 develop 并拉取最新代码
3. `git checkout -b wumeiwei` 创建个人分支
4. 编写代码 → `git add` → `git commit` → `git push -u origin wumeiwei`
5. 等待组长合并到 develop
